# AI Code Reviewer

## Overview
AI Code Reviewer is a simple tool designed to automate and enhance the code review process. It leverages AI to analyze code, detect bugs, suggest improvements, and ensure adherence to best practices.

## Project Structure
The project is divided into two main parts:
- **Frontend**: A React-based web interface for users to submit code and view review feedback.
- **Backend**: A Node.js backend that handles API requests, integrates with AI models to perform code analysis, and serves the results to the frontend.

## Features
- Automated code analysis and feedback
- Bug detection and code optimization suggestions
- Modern, user-friendly frontend interface
- RESTful API backend for AI integration
